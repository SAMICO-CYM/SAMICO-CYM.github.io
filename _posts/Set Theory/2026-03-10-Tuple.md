## Definition
Let $J$ be an index set. Given a set $X$, we define a ***$J$-tuple*** of elements of $X$ to be a function $\mathbf{x}: J \to X$. If $\alpha \in J$, then we denote $x_\alpha = \mathbf{x}(\alpha)$, which is called the $\alpha$-th ***coordinate*** of $\mathbf{x}$. The set of all $J$-tuples of elements of $X$ is denoted by $X^J$. 

**(i)** If $J = \{ 1, ..., m \}$, we denote $\mathbf{x}$ by $(x_1, ..., x_m)$.

**(ii)** If $J = \mathbb{N}$, we denote $\mathbf{x}$ by $(x_1, x_2, ...)$ or $\\{ x_n \\}_{n \in \mathbb{N}}$. In this case, we call $\mathbf{x}$ a ***sequence***.
